**Goal:** Ship a Winamp-inspired desktop jukebox that non-destructively plays and batch-converts local audio to Concert-A (default 432 Hz) or Solfeggio note-lock tunings (e.g. C5=528 heart) without bogus multi-semitone “A=528” wrecks.

**Architecture:** Tauri v2 (Rust + React). One DSP primitive: pitch-shift by `ratio = A4_target / A4_source` (tempo fixed). `A4_source` from detector (Python/librosa v1); `A4_target` from **Concert-A** or **Optimal Note Lock** resolver. SQLite library tracks sources + converted renders. Convert mode writes a parallel library; playback can use live shift or pre-converted files. Stream intercept is post-v1.

**UI theme SSOT:** `docs/design/theme-neon-glass-jukebox.md` + `docs/design/references/theme-ref-jukebox-dark.png` (Winamp IA, neon glass skin).

**RE-Tune module:** First-class UI panel (not a buried settings page) for mode/preset, lock readout, cents meter, Preview A/B, Apply-to-play, Queue-convert. Shares `resolve_target` + engine ratio; no separate DSP path.

**Tech Stack (original plan):** Rust (symphonia, rubato/cpal, rusqlite, Tauri 2), React+TS+Vite+Tailwind, Python+librosa detector, ffmpeg for encode, cargo test + vitest.

pub fn ratio_to_target(source_a4: f64, target_a4: f64) -> f64 {

/// cents(a, b) = 1200 * log2(a/b)  — how far a is from b
pub fn cents(a: f64, b: f64) -> f64 {
    1200.0 * (a / b).log2()

**Step 3: Implement `lock.rs`**

```rust
use super::math::{cents, ratio_to_target};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PitchClass {
    C = 0, Cs = 1, D = 2, Ds = 3, E = 4, F = 5,
    Fs = 6, G = 7, Gs = 8, A = 9, As = 10, B = 11,
}

const NAMES: [&str; 12] = ["C","C#","D","D#","E","F","F#","G","G#","A","A#","B"];

#[derive(Debug, Clone)]
pub struct TargetResolution {
    pub a4_target: f64,
    pub ratio: f64,
    pub shift_cents: f64,
    pub score_cents: f64,
    pub midi: i32,
    pub note: String,
    pub lock_hz: f64,
    pub ok: bool,
    pub mode: &'static str,
}

fn note_name(midi: i32) -> String {
    let pc = ((midi % 12) + 12) % 12 as usize;
    let oct = midi / 12 - 1;
    format!("{}{}", NAMES[pc as usize], oct)
}

fn a4_for_lock(freq: f64, midi: i32) -> f64 {
    freq * 2f64.powf((69.0 - midi as f64) / 12.0)
}

pub fn resolve_concert_a(a4_src: f64, a4_tgt: f64) -> TargetResolution {
    let shift = cents(a4_tgt, a4_src);
    TargetResolution {
        a4_target: a4_tgt,
        ratio: ratio_to_target(a4_src, a4_tgt),
        shift_cents: shift,
        score_cents: shift.abs(),
        midi: 69,
        note: "A4".into(),
        lock_hz: a4_tgt,
        ok: true,
        mode: "concert_a",
    }
}

pub fn resolve_solfeggio_lock(
    f_hz: f64,
    a4_src: f64,
    preferred: Option<PitchClass>,
    midi_lo: i32,
    midi_hi: i32,
    max_abs_cents: f64,
) -> TargetResolution {
    let mut try_resolve = |pc_filter: Option<i32>| -> Option<TargetResolution> {
        let mut best: Option<TargetResolution> = None;
        for n in midi_lo..=midi_hi {
            if let Some(pc) = pc_filter {
                if n.rem_euclid(12) != pc {
                    continue;
                }
            }
            let a4 = a4_for_lock(f_hz, n);
            let shift = cents(a4, a4_src);
            let cand = TargetResolution {
                a4_target: a4,
                ratio: ratio_to_target(a4_src, a4),
                shift_cents: shift,
                score_cents: shift.abs(),
                midi: n,
                note: note_name(n),
                lock_hz: f_hz,
                ok: shift.abs() <= max_abs_cents,
                mode: "solfeggio_lock",
            };
            let replace = match &best {
                None => true,
                Some(b) => {
                    cand.score_cents < b.score_cents - 1e-9
                        || ((cand.score_cents - b.score_cents).abs() < 1e-9
                            && (cand.midi - 60).abs() < (b.midi - 60).abs())
                }
            };
            if replace {
                best = Some(cand);
            }
        }
        best
    };

    let preferred_pc = preferred.map(|p| p as i32);
    if let Some(pc) = preferred_pc {
        if let Some(r) = try_resolve(Some(pc)) {
            if r.ok {
                return r;
            }
        }
    }
    // auto degree fallback
    try_resolve(None).unwrap_or_else(|| resolve_concert_a(a4_src, a4_src))
}
```

```rust
#[derive(Debug, Clone, serde::Deserialize)]
pub struct ResolveRequest {
    pub a4_src: f64,
    pub mode: String,           // concert_a | solfeggio_lock
    pub concert_a4: Option<f64>,
    pub f_hz: Option<f64>,
    pub preferred_pc: Option<u8>,
    pub max_abs_cents: Option<f64>,
}

#[tauri::command]
pub fn resolve_target(req: ResolveRequest) -> Result<crate::tuning::lock::TargetResolution, String> {
    let max_c = req.max_abs_cents.unwrap_or(80.0);
    match req.mode.as_str() {
        "concert_a" => {
            let tgt = req.concert_a4.unwrap_or(req.a4_src);
            Ok(crate::tuning::lock::resolve_concert_a(req.a4_src, tgt))
        }
        "solfeggio_lock" => {
            let f = req.f_hz.ok_or("f_hz required")?;
            let pc = req.preferred_pc.map(|p| /* into PitchClass */ unsafe_pc(p));
            Ok(crate::tuning::lock::resolve_solfeggio_lock(f, req.a4_src, pc, 36, 96, max_c))
        }
        _ => Err("unknown mode".into()),
    }
}
```

## Risks, tradeoffs, open questions

1. **12-TET single ratio** cannot satisfy A=432 and C=528 together — product must educate via readout + dual render.  
2. **Key-aware tonic lock** (528 on the song’s tonic, not always C) needs key detection — schedule **v1.1** after lock math ships.  
3. **Rubato vs Rubber Band** quality; swap if artifacts on vocals.  
4. **Python detector** packaging on Windows — document PATH; later embed.  
5. **Stream intercept** (Spotify/YTM): WASAPI loopback / virtual cable — **v1.2+**, same `ratio` applied to capture stream.  
6. **Solfeggio lists vary** (174…963 vs older 6-tone sets) — keep frequencies data-driven in `presets.rs`.  
7. **“Nice fraction”** = exact 12-TET membership of F under chosen A4; we do **not** invent continuous temperaments in v1.
