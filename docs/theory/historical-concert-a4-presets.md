# Historical concert A4 presets (Convert432)

Sources: Wikipedia *Concert pitch*; period-performance conventions.  
**Caveat:** pre-19th-c. pitch was not a single number — these are *representative* targets for retune, not claims that every Bach performance sat exactly here.

| ID | Label | A4 Hz | Era / figure | Notes |
|----|-------|------:|--------------|-------|
| `baroque_415` | Baroque Kammerton | **415** | Bach-era chamber (HIP) | Modern period default ≈ 1 semitone below A440 |
| `handel_422` | Handel 1740 | **422.5** | Handel tuning fork | Documented fork pitch |
| `classical_430` | Classical chamber | **430** | Mozart / early Beethoven HIP | Common “Classical pitch” band |
| `scientific_430` | Scientific C256 | **430.54** | 19th-c. math pitch | C4 = 256 ⇒ A4 ≈ 430.54 |
| `verdi_432` | Verdi | **432** | Verdi preference | Slightly below French 435; singer-friendly |
| `french_435` | Diapason normal | **435** | France 1859; Debussy-era FR | Legal French standard; late Romantic FR |
| `iso_440` | ISO 16 | **440** | 1939 international | Modern default |
| `berlin_443` | Berlin Phil | **443** | late 20th–21st c. | Brighter modern orchestra |
| `beethoven_455` | Beethoven fork | **455.4** | ~1800 fork (BL) | High; ~+60 ¢ from 440 — warn rail |
| `court_392` | French court low | **392** | Baroque FR court | ~−200 ¢ — only with override |
| `chorton_466` | Chorton high | **466** | Bach-era choir/organ high | ~+100 ¢ — danger / confirm |

**UI rule:** Concert A mode lists these as presets. Solfeggio mode lists chakra locks separately. Mode is parent; presets are children.
